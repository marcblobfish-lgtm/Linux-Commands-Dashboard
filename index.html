Debian & Ubuntu – Die wichtigsten Befehle auf einen Blick

📊 Übersicht

Wähle eine Kategorie und kopiere dir den Befehl mit einem Klick!

⚙️

Systemverwaltung

whoami
Zeigt den aktuellen Benutzernamen an
date
Zeigt aktuelles Datum und Uhrzeit an
uptime
Zeigt an, wie lange das System läuft
hostname
Zeigt den Hostnamen des Systems
uname -a
Zeigt alle Systeminformationen (Kernel, Architektur, etc.)
lscpu
Zeigt detaillierte CPU-Informationen
free -h
Zeigt den Speicherverbrauch in human-readable Format
df -h
Zeigt belegten und freien Speicherplatz
lsblk
Zeigt alle Blockgeräte (Festplatten, Partitionen)
top
Echtzeit-Monitoring der Systemressourcen
📦

Paketverwaltung (APT)

sudo apt update
Aktualisiert die Paketlisten
sudo apt upgrade
Aktualisiert alle installierten Pakete
sudo apt install [paket]
Installiert ein Paket (z.B. nginx, curl)
sudo apt remove [paket]
Deinstalliert ein Paket
sudo apt autoremove
Entfernt nicht mehr benötigte Abhängigkeiten
sudo apt full-upgrade
Komplettes Systemupgrade (auch mit Paketwechsel)
apt list --installed
Listet alle installierten Pakete
apt search [suchbegriff]
Sucht nach Paketen
dpkg -l | grep [suchbegriff]
Sucht nach installierten Paketen
sudo apt clean
Löscht heruntergeladene .deb-Dateien
🔄

Systemctl & Dienste

systemctl status [dienst]
Prüft den Status eines Dienstes
sudo systemctl start [dienst]
Startet einen Dienst
sudo systemctl stop [dienst]
Stoppet einen Dienst
sudo systemctl restart [dienst]
Startet einen Dienst neu
sudo systemctl enable [dienst]
Aktiviert einen Dienst zum Starten beim Booten
sudo systemctl disable [dienst]
Deaktiviert einen Dienst vom Starten beim Booten
systemctl list-units --type=service
Listet alle Dienste auf
journalctl -u [dienst]
Zeigt Logs eines Dienstes
📁

Dateiverwaltung

ls -la
Listet alle Dateien detailliert auf
cd [verzeichnis]
Wechselt in ein Verzeichnis
mkdir [name]
Erstellt ein neues Verzeichnis
rm [datei]
Löscht eine Datei
rm -r [verzeichnis]
Löscht ein Verzeichnis rekursiv
cp [quelle] [ziel]
Kopiert eine Datei
mv [quelle] [ziel]
Verschiebt/umbenennt eine Datei
touch [datei]
Erstellt eine leere Datei
cat [datei]
Zeigt den Inhalt einer Datei
find / -name [suchbegriff]
Sucht nach Dateien im System
du -sh [verzeichnis]
Zeigt den Speicherplatz eines Verzeichnisses
wc -l [datei]
Zählt Zeilen in einer Datei
🌐

Netzwerk

ip a
Zeigt alle Netzwerkinterfaces
ip addr show
Zeigt IP-Adressen der Interfaces
ip route
Zeigt die Routing-Tabelle
ping [host]
Testet die Erreichbarkeit
ifconfig
Zeigt Netzwerkkonfiguration (wenn installiert)
netstat -tuln
Zeigt offene Ports
ss -tuln
Moderne Alternative zu netstat
curl ifconfig.me
Zeigt die öffentliche IP-Adresse
wget [url]
Lädt Dateien aus dem Internet herunter
nslookup [domain]
Löst Domain-Namen in IPs auf
traceroute [host]
Zeigt den Weg der Pakete
🔐

Berechtigungen & Nutzer

chmod 755 [datei]
Ändert Dateiberechtigungen
chmod -R 755 [verzeichnis]
Ändert Berechtigungen rekursiv
chown [nutzer]:[gruppe] [datei]
Ändert den Datei-Eigentümer
sudo chown -R [nutzer]:[gruppe] [verzeichnis]
Ändert Eigentümer rekursiv
sudo useradd -m [nutzer]
Erstellt einen neuen Benutzer
sudo usermod -aG sudo [nutzer]
Fügt Benutzer zur sudo-Gruppe hinzu
sudo passwd [nutzer]
Ändert das Passwort eines Benutzers
sudo visudo
Bearbeiten der sudoers-Datei
🔀

Git & Version Control

git init
Initialisiert ein neues Git-Repository
git clone [url]
Klont ein Repository
git add .
Fügt alle Änderungen zur Staging-Area hinzu
git commit -m "Nachricht"
Kommitiert Änderungen mit Nachricht
git push -u origin main
Pushed Änderungen zu Remote
git pull
Holt und merged Änderungen von Remote
git status
Zeigt den aktuellen Status
git branch
Listet alle Branches
git checkout -b [name]
Erstellt und wechselt zu neuem Branch
🐳

Docker

sudo docker ps
Zeigt alle laufenden Container
sudo docker images
Zeigt alle Docker-Images
sudo docker pull [image]
Lädt ein Docker-Image herunter
sudo docker run -d -p 80:80 [image]
Startet einen Container im Hintergrund
sudo docker stop [container]
Stoppt einen Container
sudo docker rm [container]
Löscht einen Container
sudo docker logs [container]
Zeigt die Logs eines Containers
sudo docker build -t [name] .
Baut ein neues Docker-Image
🛡️

Firewall & Sicherheit

sudo ufw status
Zeigt den Status der UFW-Firewall
sudo ufw allow 80
Ermöglicht Port 80
sudo ufw enable
Aktiviert die UFW-Firewall
sudo ufw disable
Deaktiviert die UFW-Firewall
sudo ufw allow ssh
Ermöglicht SSH-Zugriff
sudo ufw deny 23
Blockiert Port 23 (Telnet)
⏰

Cron Jobs & Automatisierung

crontab -e
Bearbeiten der Cron-Jobs
crontab -l
Listet die Cron-Jobs
0 5 * * * /script.sh
Cron-Beispiel: Jeden Tag um 5 Uhr
*/5 * * * * /script.sh
Alle 5 Minuten ausführen
sudo service cron restart
Startet den Cron-Dienst neu
📋

Logs & Debugging

journalctl -xe
Zeigt die neuesten Systemlogs
tail -f /var/log/syslog
Überwacht Logs in Echtzeit
cat /var/log/auth.log
Zeigt Authentifizierungslogs
grep -i "error" /var/log/syslog
Sucht nach "error" in Logs
dmesg | tail
Zeigt Kernel-Logs
lsof -i :80
Zeigt Prozesse auf Port 80
